Grant Agreements

Agreement templates are versioned and append-only. Publishing a new version requires grantees to re-accept. The version body is hashed so each acceptance proves exactly which terms were shown.

Publish a new version
Write in Markdown. Use {{token}} placeholders; they are filled in server-side when a grantee views/accepts.
Grantee / signer (from the acceptance form): {{grantee_legal_name}}, {{grantee_country}}, {{grantee_address}}, {{signer_name}}, {{signer_title}}, {{signer_email}}.
Grantor (from governance config): {{grantor_legal_name}}, {{grantor_address}}, {{grantor_exempt_purpose}}.
Grant details (from the most recent board approval for the grantee): {{grant_amount}}, {{grant_schedule}}, {{grant_purpose}}, {{grant_term}}, {{grant_reference}}.
System: {{version_label}}, {{date_accepted}}. Any other {{token}} is filled from a matching key in the terms JSON below (unknown tokens are left as-is).
For template-level defaults only. Grant financials (amount, schedule, purpose, term) come from the board approval, not here. Any key set here is also usable as a {{key}} token (lowest priority).
